Greedy Nose — UI Mocks

Static, framework-agnostic phone mocks for the bank-transaction / bad-debitor-alert app. Layout uses flexbox throughout so it maps fairly directly to React Native, and serves as a precise blueprint if implemented in Flutter or another stack instead.

Flow: connect bank → one-time onboarding review of existing debitors → every debitor defaults to Bad until marked Trusted → manage rules (with optional amount/frequency thresholds) → get notified next time a bad debitor charges you.
